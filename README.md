# E-Commerce Sales Analysis & Power BI Dashboard

## Overview
This repository contains a complete end-to-end data science and business intelligence project analyzing e-commerce transactional data. The project covers data cleaning, exploratory data analysis (EDA) using Python, and an interactive Power BI dashboard for actionable business insights.

## Project Structure
- `week1_analysis.ipynb`: Jupyter notebook containing data preprocessing, cleaning, and exploratory data analysis.
- `ecommerce_final_processed.csv`: The final cleaned dataset ready for modeling and reporting.
- `e-commers Analystic.pbix`: Interactive Power BI dashboard featuring core KPIs, regional sales, payment breakdown, and delivery tracking.
- `final_report.docx`: Detailed project report containing findings and strategic recommendations.

## Key Insights
- **Top Cities:** Nagpur, Pune, and Mumbai are the top revenue-generating cities.
- **Payment Preferences:** Credit Card and UPI dominate customer transactions.
- **Fulfillment Efficiency:** ~72.4% of orders are successfully delivered, with a low cancellation rate of ~6.6%.
- **Product Performance:** Identified top-performing categories and high-revenue products.

## Tools & Technologies Used
- **Python** (Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook)
- **Power BI** (DAX measures, Data Modeling, Custom Visual Layouts)
- **Git & GitHub** for version control
